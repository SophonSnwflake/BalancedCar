Self-balancing car (created in August 2025), using the standard library.


## 平衡车

基于经典STM32F104C8T6，驱动代码是从江科大抄的，我写一些控制逻辑。

代码结构是标准库，没有使用freertos和hal。

不过硬件和机械结构是自己设计的，没有直接买江科大的套件。

可以行进，平衡没有问题，最开始我的板子预留了一个lora透传串口，然后可以使用LoRa用电脑串口进行通信，但是有点延迟。而且Lora通信法案似乎不让用Lora频段作为控制器（

然后我又打样了一批板子，上面预留了蓝牙模块接口，但是接上去后发现蓝牙收不到信号？不确定是蓝牙模块的问题还是板子打样的问题。

然后就赶上我去负责队内的哨兵了，这个小玩具就从此无限搁置了。

现在开机应该还能平衡，但是控制还是只能用LoRa。
